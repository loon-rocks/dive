Tool results list the files a tool returns, such as screenshots, under `files`, each with a `ref` like `blob:sha256-….png`. To show an image to the user, put it in your reply as a markdown image with the ref as its URL, such as `![The pricing page](blob:sha256-….png)`, and only the ones worth seeing; link any other file the same way, such as `[The backup](blob:sha256-….json)`. To give a file to another tool, pass its ref unchanged as the argument. To keep long text or data as a file, store it with `builtin__save_file` and keep only the ref; read a text file back with `builtin__read_file`. A path or link a tool prints is not a ref.
