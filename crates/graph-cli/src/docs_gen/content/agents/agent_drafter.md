## How it works

1. Asks what the agent is for, and whether it's for conversation, plan steps, or both.
2. Searches the catalog for the tools it needs.
3. Writes the agent file and shows it to you.
4. Saves it to `.graph/agents/` after you confirm. You can use it right away.

In the workbench, use `graph wb agent` instead.
