---
summary: The agents that ship with Dive.
---

Every built-in agent runs in `dive ask`, `dive chat`, plan steps and `dive wb`, and any agent can name any other as a handoff or subagent. The workbench agents are the ones `dive wb` starts with; they create or open the network draft they work on when they need one. A file in `.dive/agents/` or `~/.config/dive/agents/` with the same name replaces a built-in agent.
