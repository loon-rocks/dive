## How it works

1. Asks what the agent is for, and whether it's for conversation, plan steps, or both.
2. Searches the catalog for the tools it needs.
3. Writes the agent file to the same design principles as the workbench's architect, and shows it to you.
4. Saves it to `.dive/agents/` after you confirm. You can use it right away.

In the workbench, use `dive wb agent` instead.
