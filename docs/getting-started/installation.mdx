## Release binaries

Tagged releases publish binaries for macOS (arm64) and Linux (x86_64) with SHA-256 checksums.

<BinaryDownloads />

Or from the command line:

<Tabs>
  <Tab title="macOS (arm64)">
    ```bash
    curl -fsSLO "https://github.com/loon-rocks/dive/releases/download/{{release_version}}/graph-{{release_version}}-macos-arm64.tar.gz"
    tar xzf graph-*.tar.gz && install -m 0755 graph ~/.local/bin/
    graph --help
    ```
  </Tab>
  <Tab title="Linux (x86_64)">
    ```bash
    curl -fsSLO "https://github.com/loon-rocks/dive/releases/download/{{release_version}}/graph-{{release_version}}-linux-x86_64.tar.gz"
    tar xzf graph-*.tar.gz && install -m 0755 graph ~/.local/bin/
    graph --help
    ```
  </Tab>
</Tabs>

<Info>
  On macOS, the first run of a freshly downloaded binary pauses ~1s while Gatekeeper scans it. Every run after that is instant.
</Info>

## Container image

Each release also publishes [ghcr.io/loon-rocks/dive](https://github.com/loon-rocks/dive/pkgs/container/graph) with git, gh, jq and curl installed, ready to use in CI:

```bash
docker run --rm \
           -e ANTHROPIC_API_KEY \
           -e DIVE_STORAGE=memory \
           -v "$PWD:/work" \
           -w /work \
           ghcr.io/loon-rocks/dive:{{release_version}} plan list
```

## Requirements

| Requirement | Notes |
| --- | --- |
| macOS (arm64) or Linux (x86_64) | the platforms release binaries are published for |
| An LLM provider key | e.g. `ANTHROPIC_API_KEY` — see [Quickstart](/quickstart) |

## First-run notes

- graph creates its [data directory](/reference/data-directory) at `~/.local/share/dive/` on first use (configurable via `[settings] data_dir`).
- State is plain files under the data directory, safe under concurrent runs. Use `DIVE_STORAGE=memory` for ephemeral runs that should leave nothing behind.
