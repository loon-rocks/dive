---
title: "Built-in plans"
description: "The plans that ship with graph."
keywords: ["Built-in plans"]
---

Agents and plans call them as `plan__<identifier>`. A plan file with the same identifier replaces a built-in plan.

| Name | Description |
| --- | --- |
| [`compose_plan`](/plans/reference/built-in/compose_plan) | Drafts a whole plan for a goal from the tools in your catalog. |
| [`search_tools`](/plans/reference/built-in/search_tools) | Finds the catalog tools that fit a task, most likely first. |
