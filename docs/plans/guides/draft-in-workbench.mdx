## Draft the plan

<Steps>
  <Step title="Open the workbench in plan mode">
    ```bash
    dive workbench plan
    ```
  </Step>
  <Step title="Describe the goal">
    Say what the plan should produce and from what:

    ```text
    a plan called unreleased_changes that writes a
    one-line release note for each commit since the
    latest GitHub release, from its subject and the
    files it changed
    ```

    The drafting architect asks what it can't settle, one question at a time with its guess and its confidence. The workspace shows what it knows so far.

    <Frame caption="The architect's question, with its guess and what it knows so far.">
      <img src="/images/workbench/plan-drafting-questions.svg" alt="The workbench with network_drafter asking whether merge commits should get a note of their own, guessing no, and the workspace showing the interview at 75% confidence with the outcome and source known and merge commits being asked about." />
    </Frame>

    It restates what it'll build for you to confirm, then sketches the plan in the workspace with the model role and design principles it uses: here a map that fetches each commit's changed files in parallel, and one small-model call for all the notes.
  </Step>
  <Step title="Build it">
    Tell the architect to build. The plan drafter writes down the steps the sketch lists, checks the plan, and puts it in the workspace. The architect then test-runs it and tells you how the test went:

    <Frame caption="The drafted plan in the workspace: the release, the commits since it, each commit's changed files, and one infer step that writes the notes.">
      <img src="/images/workbench/plan-drafted.svg" alt="The workbench after building: the architect's summary on the left, and on the right the restate and the unreleased_changes plan with steps release, commits, a file_changes map and notes, with no problems." />
    </Frame>
  </Step>
  <Step title="Save">
    Press <kbd>Ctrl</kbd>+<kbd>S</kbd>. graph writes the plan to `./.dive/plans/unreleased_changes.yaml`.
  </Step>
</Steps>

## Run the plan

```bash
dive plan run unreleased_changes
```
