title: "Iterate with map and reduce"
description: "Write a release note for each commit with map, then join the notes into one changelog with reduce."

---

`unreleased_changes` writes a note for every commit since the latest release, four commits at a time, and joins the notes into one changelog.

<RequestExample>

```yaml .dive/plans/unreleased_changes.yaml
version: 2
identifier: unreleased_changes
name: Unreleased changes
description: A release note for each commit since the latest release, joined into one list.
steps:
- id: release
  tool_name: github__tool__gh_release
  input: {}
- id: commits
  tool_name: github__tool__git_log
  input:
    base: '{{release.tag}}'
    head: HEAD
- id: notes
  tool_name: map
  input:
    over: '{{commits.commits}}'
    concurrency: 4
    do:
    - id: files
      tool_name: github__tool__git_changed_files
      input:
        base: '{{item.sha}}~1'
        head: '{{item.sha}}'
        prefix: ''
    - id: note
      tool_name: builtin__infer
      input:
        instruction: |-
          Write one release-note line for this commit.
          Subject: {{item.subject}}
          Files changed: {{files.files}}
- id: changelog
  tool_name: reduce
  input:
    over: '{{notes.results}}'
    initial:
      text: ''
    do:
      tool_name: builtin__reshape
      input:
        shape:
          text: |-
            {{accumulator.text}}
            - {{item.text}}
finish:
  output:
    since: '{{release.tag}}'
    changelog: '{{changelog.result.text}}'
```

</RequestExample>

## Run steps for each commit with map

The `notes` step is a `map`:

- `over` is the list, here the commits from `git_log`.
- `do` holds the steps that run once per item. `{{item}}` is the current commit.
- `concurrency: 4` runs four commits at a time.

Each item's result is the result of its last step, and `{{notes.results}}` lists them in the same order as the commits.

## Join the notes with reduce

The `changelog` step is a `reduce`. It runs `do` once per note, in order:

- `{{accumulator}}` starts as `initial`, and each run's result becomes the next `{{accumulator}}`.
- Here each run adds the note `{{item.text}}` as a new line under the text so far.

The final value is `{{changelog.result}}`.

## Run it

```bash
dive plan run unreleased_changes
```

stderr shows the `map` starting four commits at once, then the `reduce` working through the notes:


```json
{
  "changelog": "\n- **Breaking change:** Plans must now declare a required `finish` key…\n- **BREAKING:** Workbench agents now operate on plans using the same unified artifact tools…\n…",
  "since": "{{release_version}}"
}
```
