---
title: "Create an agent in the workbench"
description: "Use the workbench's drafting architect to design an agent, and any tools or plans it needs, and save them together."
keywords: ["agent drafter", "network_drafter", "workbench", "create agent"]
---

The drafting architect designs the agent with you, sketches it with any tools or plans it needs, and has the builders draft each one. You save them together when they're right.

## Draft the agent

<Steps>
  <Step title="Open the workbench in agent mode">
    ```bash
    dive workbench agent
    ```
  </Step>
  <Step title="Answer the architect's questions">
    Say what the agent is for, what it reads and what it produces. The architect asks what it can't settle, one question at a time with its guess, including whether the agent is for conversation, [plan](/plans/overview) steps, or both. It ends with a restate of what it'll build, including what's out of scope, for you to confirm.
  </Step>
  <Step title="Review the sketch">
    The sketch in the workspace lists every piece with its job, model role and the design principles it applies. When the agent needs a tool that doesn't exist, the tool is a node of its own.

    <Frame caption="A sketch with the agent and the tool it needs.">
      <img src="/images/workbench/agent-missing-tool.svg" alt="The workbench with network_drafter active: it explains that no tool can post to the changelog page, so the sketch adds post_changelog, and the workspace shows the restate, the post_changelog tool node and the release_notes agent node that calls it." />
    </Frame>

    Change anything in chat. The architect pushes back once when a change costs more than the job needs, then does what you choose.
  </Step>
  <Step title="Build it">
    Tell the architect to build. The agent drafter writes the agent file, the tool drafter writes and test-runs the tool, and the architect tests the network on a realistic message, on each agent's own model.

    <Frame caption="The agent drafter's file in the workspace.">
      <img src="/images/workbench/agent-drafting.svg" alt="The workbench after building: the architect's summary on the left, and the release_notes agent draft on the right with its description, model, tools, input, output and system prompt." />
    </Frame>
  </Step>
  <Step title="Save">
    Press <kbd>Ctrl</kbd>+<kbd>S</kbd>. Dive writes tools to `./.dive/tools/` and the agent to `./.dive/agents/<name>.yaml`.
  </Step>
</Steps>

## Run the agent

```bash
dive ask --agent release_notes \
  "What shipped since v0.15.0?"
```
