## Connect a web server

Add the [fetch](https://github.com/modelcontextprotocol/servers/tree/main/src/fetch) MCP server to `.graph/config.toml`. Its `fetch` tool joins your catalog as `web__fetch`:

```toml .graph/config.toml
[mcp.web]
description = "Fetches web pages as markdown"
command = "uvx"
args = ["mcp-server-fetch"]
```

## Create the researcher

```yaml .graph/agents/researcher.yaml
version: 1
name: researcher
description: Researches a question on the internet and answers with sources.
model: chat
tools:
- web__fetch
system_prompt: |
  You research questions on the internet. Fetch the pages you need, then
  answer briefly and list the URLs you used.
```

## Copy the chat agent

A file named `chat` in your project replaces the built-in:

```bash
graph agent show chat \
  > .graph/agents/chat.yaml
```

## Add the subagent

Add `researcher` to `subagents`, and tell `chat` when to use it in `system_prompt`:

```yaml .graph/agents/chat.yaml
subagents:
- chat
- researcher
system_prompt: |
  …
  - When a question needs current information from the internet, give it to agent__researcher and cite the sources it returns.

  Today's date: {{session.date}}
  {{session.user}}
```

## Try it

```bash
graph ask "What is the latest stable version of Rust?"
```

`chat` hands the question to `researcher`, which fetches the pages:

