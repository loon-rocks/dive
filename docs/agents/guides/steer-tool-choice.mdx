## See what the agent calls

This `digest` plan gathers the commits since the latest release, but its description doesn't say so:

```yaml .dive/plans/digest.yaml
version: 2
identifier: digest
name: Digest
description: Team digest.
steps:
- id: release
  tool_name: github__tool__gh_release
  input: {}
- id: commits
  tool_name: github__tool__git_log
  input:
    base: '{{release.tag}}'
    head: HEAD
finish:
  output:
    since: '{{release.tag}}'
    commits: '{{commits.commits}}'
```

Ask a question the plan answers:

```bash
dive ask "What have we merged since we last shipped?"
```

`chat` skips the plan and makes the same calls itself:

```text
→ github__tool__gh_release {}
✓ github__tool__gh_release 1.1s
→ github__tool__git_log {"base":"{{release_version}}","head":"HEAD"}
✓ github__tool__git_log 72.9ms
```

## Describe the plan and add exemplars

Say what the plan returns in `description`, and list questions it answers under `exemplars`. The agent reads both in the plan's tool description:

```yaml .dive/plans/digest.yaml
description: Team digest. The commits merged since the latest GitHub release.
exemplars:
- What have we merged since the last release?
- What's unreleased?
```

## Ask again

```bash
dive ask "What have we merged since we last shipped?"
```

`chat` now calls the plan:

```text
→ plan__digest {}
  → github__tool__gh_release {}
  ✓ github__tool__gh_release 995.2ms
  → github__tool__git_log {"base":"{{release_version}}","head":"HEAD"}
  ✓ github__tool__git_log 50.5ms
✓ plan__digest 1.0s
```
