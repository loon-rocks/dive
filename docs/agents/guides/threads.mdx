## Find the thread

```bash
graph thread list
```

```text
169a26420daf  2026-10-13 13:46    4 msgs  What is the latest stable version of Rust?
```

## Read it

```bash
graph thread show 169a26420daf
```

The thread records each message with its author, every tool call, and the subagents that ran:

```text
169a26420daf — What is the latest stable version of Rust? (4 messages, updated 2026-10-13 13:46; owner chat, active chat)

user> What is the latest stable version of Rust?

  → agent__researcher {"prompt":"What is the latest stable version of the Rust programming language…"}

  ✓ {"result":"As of October 2026, the latest stable version of the Rust programming language is **Rust 1.99.0**…"}

chat> The latest stable version of Rust is **1.99.0**, released October 1, 2026.

  ↳ chat ran researcher (8 messages)
```

## Continue it

Pass the thread's id with `--thread`, after the message:

```bash
graph ask "When is the next one due?" \
  --thread 169a26420daf
```

```text
The next stable release, **Rust 1.100.0**, is due **November 12, 2026**…
```

## Delete it

```bash
graph thread rm 169a26420daf
```

```text
deleted 169a26420daf
```
