## Find the thread

```bash
dive thread list
```

```text
169a26420daf  2026-10-13 13:46    4 msgs  What is the latest stable version of Rust?
```

A thread belongs to the project it was started in: the current directory when it has a `.dive` folder. `dive thread list` lists the threads of the project you're in, or the global threads outside one. Add `--all` to list every thread:

```bash
dive thread list --all
```

The other `dive thread` commands take a thread's id, so they work on any thread from anywhere.

## Read it

```bash
dive thread show 169a26420daf
```

The thread records each message with its author, every tool call, and the subagents that ran:

```text
169a26420daf — What is the latest stable version of Rust? (4 messages, updated 2026-10-13 13:46; owner chat, active chat)

user> What is the latest stable version of Rust?

  → agent__researcher {"prompt":"What is the latest stable version of the Rust programming language…"}

  ✓ {"result":"As of October 2026, the latest stable version of the Rust programming language is **Rust 1.99.0**…"}

chat> The latest stable version of Rust is **1.99.0**, released October 1, 2026.

  ↳ chat ran researcher (8 messages)
```

## Continue it

Pass the thread's id with `--thread`, after the message:

```bash
dive ask "When is the next one due?" \
  --thread 169a26420daf
```

```text
The next stable release, **Rust 1.100.0**, is due **November 12, 2026**…
```

A thread where the drafting architect built a network of tools, plans and agents reopens with that network, rebuilt from the thread's history:

```bash
dive chat --thread 4be1c0a9d2e7
```

An edit thread, opened by `network_editor` on the agents, plans or tools to fix, reopens the same way, with those items, its sketch, the edits made to them, any new items and the call the edit started from.

## Delete it

```bash
dive thread rm 169a26420daf
```

```text
deleted 169a26420daf
```

Deleting a thread also removes the stored files, such as generated images, that no other thread refers to, and the output says how many. Files in S3 storage are kept, since other machines may share the bucket.
