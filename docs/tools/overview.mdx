A tool is anything an [agent](/agents/overview) or a [plan](/plans/overview) step can call. Every tool sits in one catalog, and its name says where it comes from.

## Where tools come from

| Source | Named | Add one |
| --- | --- | --- |
| Your tool files | `user__<name>` | [Create a tool in the workbench](/tools/guides/create-in-workbench) |
| Built-in tools | `builtin__<name>` | [Built-in tools](/tools/reference/builtin-tools) |
| Packs | `<pack>__tool__<name>` | [Packs](/packs/overview) |
| MCP servers | `<server>__<tool>` | [Connect an MCP server](/integrating/mcp/guides/connect-mcp-server) |
| Plans | `plan__<identifier>` | [Plans](/plans/overview) |
| Agents | `agent__<name>` | [Agents](/agents/overview) |

Because plans and agents are tools too, anything you build can be called by the next thing you build.

## Tool files

A tool file is a YAML file in `./.dive/tools/` or `~/.config/dive/tools/`. Its `kind` decides what it runs:

| Kind | Runs | Calls a model |
| --- | --- | --- |
| [`exec`](/tools/reference/tool-file/exec) | A command | No |
| [`prompt`](/tools/reference/tool-file/prompt) | One model call with a prompt | Yes |
| [`reshape`](/tools/reference/tool-file/reshape) | A rebuild of JSON from the input | No |
| [`decision`](/tools/reference/tool-file/decision) | Questions to a decision model | Yes |

Only `prompt` and `decision` tools spend tokens, so moving work into `exec` and `reshape` tools makes it cheaper and repeatable.

Mark a tool `read_only` when it has no side effects. `reshape` and `decision` tools are read-only by default.

Tool names must be unique across both directories. To change a built-in tool for a project, put a file with the same name in the `builtin/` subdirectory of a tools directory, and it replaces Dive's version. `dive tool rm builtin__<name>` deletes the override and brings Dive's version back; `dive tool rm <name>` deletes a user tool. A pack is a plain copy in `packs/<name>/`, so you change its tools by editing them there; `dive pack list` reports the edits.

## Inspect and run tools

```bash
dive tool list
dive tool show github__tool__git_log
dive tool test github__tool__git_log --input base=v0.15.0
```

`dive tool list` lists the catalog, `dive tool show` prints a tool's description, schemas and source, and `dive tool test` calls it and prints the result.
