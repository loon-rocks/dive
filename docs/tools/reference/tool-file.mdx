| --- | --- |
| YAML | `./.dive/tools/<name>.yaml` (project)<br />`~/.config/dive/tools/<name>.yaml` (global)<br />`<tools dir>/builtin/<name>.yaml` (replaces a built-in tool) |

Unknown keys are a load error. For completion in your editor, start the file with `# yaml-language-server: $schema=https://raw.githubusercontent.com/loon-rocks/dive/main/docs/schemas/tool.schema.json`.

## Common fields

<ParamField body="version" type="integer">
  The file version the document is written in. Omitted means 1; `dive tool migrate` brings a file to the current version.
</ParamField>

<ParamField body="name" type="string" required>
  Letters, digits, `_` and `-`. The tool is called as `user__<name>`.
</ParamField>

<ParamField body="description" type="string" required>
  What the tool does and returns. Agents and the plan drafter read it when choosing tools.
</ParamField>

<ParamField body="kind" type="enum<string>" required>
  What the tool runs. Each kind takes its own fields, listed below.

  Available options: `exec`, `http`, `prompt`, `reshape`, `decision`, `image`
</ParamField>

<ParamField body="input_schema" type="object">
  JSON Schema for the input, validated before the tool runs. Templates reference it as `{{input.<field>}}`.
</ParamField>

<ParamField body="output_schema" type="object">
  JSON Schema for the output. A `prompt` tool enforces it as structured output; for every kind it tells drafters what the tool returns.
</ParamField>

<ParamField body="read_only" type="boolean">
  Marks the tool as free of side effects. `reshape` and `decision` tools are read-only by default, and so is an `http` tool whose method is `GET`.
</ParamField>

<ParamField body="generated" type="string">
  The generator that wrote this file, such as `dive-go`. Set by the generator, never by hand. The desktop app and the drafters show a generated tool but don't edit or overwrite it; change it in the code it's generated from, then regenerate.
</ParamField>

## Kinds

Each `kind` adds its own fields.

- [`exec`](/tools/reference/tool-file/exec): Runs a command.
- [`http`](/tools/reference/tool-file/http): Makes one HTTP request per call and returns the response body.
- [`prompt`](/tools/reference/tool-file/prompt): One model call.
- [`reshape`](/tools/reference/tool-file/reshape): Builds a value in a new JSON shape from the input, with no process and no model call.
- [`image`](/tools/reference/tool-file/image): Generates images with an image model and stores them as files.
- [`decision`](/tools/reference/tool-file/decision): Asks a decision model typed questions about the same state, each answered independently.

<RequestExample>

```yaml Example
version: 3
name: open_prs
description: Open pull requests in the current repository, newest first.
kind: exec
command: gh
args:
- pr
- list
- --state
- open
- --json
- number,title,author
- --limit
- '{{input.limit}}'
read_only: true
input_schema:
  type: object
  required:
  - limit
  properties:
    limit:
      type: integer
      description: Most pull requests to return
```

</RequestExample>
