## Behavior

- Checks the draft right away and returns any problems. Nothing is written to disk.
- For a plan, omit `yaml` to use the plan `plan__compose_plan` last returned.
- Replacing a plan draft with unsaved changes fails unless `overwrite_draft` is true.

| Available to | Effect |
| --- | --- |
| Workbench agents only | Read-only |

## Input

<ParamField body="kind" type="enum<string>" required>
  What the file is

  Available options: `plan`, `agent`, `tool`
</ParamField>

<ParamField body="overwrite_draft" type="boolean">
  Plans only: discard unsaved changes to the current plan draft, only after the user confirms
</ParamField>

<ParamField body="yaml" type="string">
  The whole file. Required for an agent or tool; omit it for a plan to publish what plan__compose_plan returned
</ParamField>
