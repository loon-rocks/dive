## Behavior

- Checks the draft right away and returns any problems. Nodes of the sketch that aren't drafted yet count as existing. Nothing is written to disk.
- Once there's a sketch, a file whose name isn't a node of it is refused.
- For a plan, omit `yaml` to use the plan `plan__compose_plan` last returned. With no network in progress, a plan goes to the plan pane, and replacing one with unsaved changes fails unless `overwrite_draft` is true.

| Available to | Effect |
| --- | --- |
| Workbench agents only | Read-only |

## Input

<ParamField body="kind" type="enum<string>" required>
  What the file is

  Available options: `plan`, `agent`, `tool`
</ParamField>

<ParamField body="overwrite_draft" type="boolean">
  Plan pane only: discard unsaved changes to the current plan draft, only after the user confirms
</ParamField>

<ParamField body="yaml" type="string">
  The whole file. Required for an agent or tool; omit it for a plan to use what plan__compose_plan returned
</ParamField>
