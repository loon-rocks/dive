## Behavior

- Carries the confirmed restate, every node with its job, model role and design principles, and the edges between nodes.
- Nodes keep their drafts across sketches. A drafted node left out of the new sketch is reported so it can be discarded.

| Available to | Effect |
| --- | --- |
| Workbench agents only | Read-only |

## Input

<ParamField body="edges" type="object[]">
</ParamField>

<ParamField body="edges.[].from" type="string" required>
  A node name
</ParamField>

<ParamField body="edges.[].kind" type="enum<string>" required>
  Available options: `handoff`, `subagent`, `calls`
</ParamField>

<ParamField body="edges.[].to" type="string" required>
  A node name, or an existing tool, plan or agent
</ParamField>

<ParamField body="nodes" type="object[]" required>
</ParamField>

<ParamField body="nodes.[].change" type="string">
  An edit: what changes in this opened item, in one line, specific enough for its builder. Omit for an opened item that stays as it is and for a new node
</ParamField>

<ParamField body="nodes.[].job" type="string" required>
  What this node does, in one sentence
</ParamField>

<ParamField body="nodes.[].kind" type="enum<string>" required>
  Available options: `agent`, `plan`, `tool`
</ParamField>

<ParamField body="nodes.[].model" type="string">
  The model role it runs on (agents, prompt tools, and plan steps that call a model); omit when it calls no model
</ParamField>

<ParamField body="nodes.[].name" type="string" required>
  The file's name: a tool name without user__, a plan identifier, or an agent name
</ParamField>

<ParamField body="nodes.[].principles" type="string[]">
  The design principles this node applies
</ParamField>

<ParamField body="nodes.[].proposed" type="boolean">
  True for a node a pending question would add
</ParamField>

<ParamField body="nodes.[].returns" type="string">
  Its output, field by field, as the nodes that read it expect it
</ParamField>

<ParamField body="nodes.[].takes" type="string">
  Its input, field by field, as the nodes that call it will pass it
</ParamField>

<ParamField body="restate" type="object" required>
</ParamField>

<ParamField body="restate.change" type="string">
  An edit: the change, in one sentence
</ParamField>

<ParamField body="restate.constraint" type="string">
  A new network: the limit it works within
</ParamField>

<ParamField body="restate.out_of_scope" type="string[]" required>
</ParamField>

<ParamField body="restate.outcome" type="string">
  A new network: what the user gets. Required unless problem and change are given
</ParamField>

<ParamField body="restate.problem" type="string">
  An edit: what went wrong, or what the user wants changed
</ParamField>

<ParamField body="restate.success" type="string" required>
  How the test shows it worked; in an edit, the evidence's input and what the answer must do
</ParamField>
