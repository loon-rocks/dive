## Behavior

- Opens user tools, built-in tools (`builtin__<name>`) and a pack's tools (`<pack>__tool__<name>`), and agents and plans wherever they come from.
- Saving the network later writes the item back: to its own file, to a project override for a built-in, or to the pack's installed copy for a pack's item, which `graph pack update` replaces.
- In a thread that is already editing items, needs a `reason` and asks you to approve attaching the item before it opens.
- Loading a plan into the plan pane over a draft with unsaved changes fails unless `overwrite_draft` is true.

| Available to | Effect |
| --- | --- |
| Workbench agents only | Read-only |

## Input

<ParamField body="kind" type="enum<string>" required>
  What to open

  Available options: `plan`, `agent`, `tool`
</ParamField>

<ParamField body="name" type="string" required>
  A plan identifier or plan file path, an agent's name, or a tool's name: user__&lt;name&gt; or a bare name, builtin__&lt;name&gt;, or &lt;pack&gt;__tool__&lt;name&gt;
</ParamField>

<ParamField body="overwrite_draft" type="boolean">
  Plan pane only: load over a plan draft with unsaved changes, only after the user confirms discarding them
</ParamField>

<ParamField body="reason" type="string">
  Why this item belongs in the edit, in a sentence the user reads when approving it. Required while the thread is editing items
</ParamField>
