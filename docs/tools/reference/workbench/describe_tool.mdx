- Returns its description, input schema, declared and observed output shape, and whether it's read-only.

| Available to | Effect |
| --- | --- |
| Workbench agents only | Read-only |

## Input

<ParamField body="name" type="string" required>
  The tool's full name, e.g. linear__list_issues or plan__project_status
</ParamField>
