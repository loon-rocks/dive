- A node of the sketch goes back to not drafted; the plan pane's plan can't be discarded.

| Available to | Effect |
| --- | --- |
| Workbench agents only | Read-only |

## Input

<ParamField body="kind" type="enum<string>" required>
  What the draft is

  Available options: `plan`, `agent`, `tool`
</ParamField>

<ParamField body="name" type="string">
  Which draft, when there are several of this kind
</ParamField>
