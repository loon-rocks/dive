- Paths outside the project directory are refused.
- Use `offset` and `limit` to page through large files.

| Available to | Effect |
| --- | --- |
| Workbench agents only | Read-only |

## Input

<ParamField body="limit" type="integer">
  Maximum lines to return. Default 500, cap 2000.
</ParamField>

<ParamField body="offset" type="integer">
  1-based line to start from. Default 1.
</ParamField>

<ParamField body="path" type="string" required>
  File path, relative to the project directory (or absolute within it).
</ParamField>

</ResponseField>

</ResponseField>

</ResponseField>

<ResponseField name="path" type="string">
</ResponseField>

</ResponseField>

</ResponseField>
