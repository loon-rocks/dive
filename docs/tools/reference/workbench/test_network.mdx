## Behavior

- Starts at an agent node with a message, or runs a plan node with an input.
- Every agent runs on its own model and tools run for real. Nothing is saved.
- Needs every node drafted without problems, and returns which nodes ran and the answer.

| Available to | Effect |
| --- | --- |
| Workbench agents only | Has side effects |

## Input

<ParamField body="entry" type="string" required>
  The agent or plan node the test starts at
</ParamField>

<ParamField body="input" type="object">
  Plans: the plan's input
</ParamField>

<ParamField body="message" type="string">
  Agents: the user message to send
</ParamField>
