- Checks the tool file, then asks you to approve the run.
- Runs it on the sample input and records its output shape.

| Available to | Effect |
| --- | --- |
| Any agent or plan step | Has side effects |

## Input

<ParamField body="input" type="object" required>
  Sample input for one run, matching the tool's input_schema
</ParamField>

<ParamField body="purpose" type="string" required>
  One sentence the user reads before approving: what this run checks, e.g. "Check it returns README.md's text and size."
</ParamField>

<ParamField body="yaml" type="string" required>
  The whole user tool file
</ParamField>
