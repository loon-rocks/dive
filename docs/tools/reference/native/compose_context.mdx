- The tools every step can use, plus the tools search found for the plan's capabilities, with their schemas.
- The step schema and the template rules.

| Available to | Effect |
| --- | --- |
| Any agent or plan step | Read-only |

## Input

<ParamField body="found" type="object[]" required>
  One entry per capability: &#123;does, tools&#125;, where tools is what plan__search_tools returned
</ParamField>

## Output

<ResponseField name="composing_rules" type="string" required>
</ResponseField>

<ResponseField name="rounds" type="integer[]" required>
</ResponseField>

<ResponseField name="standing_tools" type="string" required>
</ResponseField>

<ResponseField name="step_schema" type="string" required>
</ResponseField>

<ResponseField name="templating_rules" type="string" required>
</ResponseField>

<ResponseField name="tools" type="string" required>
</ResponseField>
