playground: "none"
keywords: ["builtin__save_tool"]
---

- The tool must pass `builtin__try_tool` first, unless `untested` is true.
- Won't replace an existing file unless `overwrite` is true.

| Available to | Effect |
| --- | --- |
| Any agent or plan step | Has side effects |

## Input

<ParamField body="overwrite" type="boolean">
  Replace an existing file with the same name, only after the user confirms
</ParamField>

<ParamField body="untested" type="boolean">
  Save without a test run, only when the user said not to test it
</ParamField>

<ParamField body="yaml" type="string" required>
  The whole user tool file, exactly as tested
</ParamField>
