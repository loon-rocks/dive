- Runs one `search_tools` search per request.
- Returns the combined list and descriptions for the next drafting call.

| Available to | Effect |
| --- | --- |
| Any agent or plan step | Read-only |

## Input

<ParamField body="found" type="object[]" required>
  The &#123;does, tools&#125; entries found so far
</ParamField>

<ParamField body="queries" type="string[]" required>
  What each missing tool should do
</ParamField>

## Output

<ResponseField name="found" type="object[]" required>
</ResponseField>

<ResponseField name="tools" type="string" required>
</ResponseField>
