---
title: "Workbench tools"
description: "Tools only the workbench's own agents can call, to act on what the workbench has open."
keywords: ["Workbench tools"]
---

- The `*_artifact` tools work the same way on plans, agents and tools: list, show, open, draft, run, save.
- The plan edit tools change one part of the open plan draft at a time.
- Plan steps, `graph chat`, `graph ask` and MCP clients can't call them. Outside the workbench, edit plans with [`graph plan set` and `graph plan step`](/reference/cli/plan), or the `graph_plan_*` [tools of `graph mcp serve`](/integrating/mcp/reference/server-tools).

| Name | Description |
| --- | --- |
| [`workbench__list_artifacts`](/tools/reference/workbench/list_artifacts) | Lists the plans, agents or tools that exist. |
| [`workbench__show_artifact`](/tools/reference/workbench/show_artifact) | Returns an existing plan, agent or user tool as YAML, without opening it in the pane. |
| [`workbench__load_artifact`](/tools/reference/workbench/load_artifact) | Opens an existing plan, agent or user tool in the pane for editing. |
| [`workbench__set_artifact`](/tools/reference/workbench/set_artifact) | Puts a whole plan, agent or tool file in the pane as the current draft. |
| [`workbench__try_artifact`](/tools/reference/workbench/try_artifact) | Runs the plan or tool draft in the pane. |
| [`workbench__save_artifact`](/tools/reference/workbench/save_artifact) | Saves the draft in the pane to the project. |
| [`workbench__discard_artifact`](/tools/reference/workbench/discard_artifact) | Discards the agent or tool draft in the pane. |
| [`workbench__update_metadata`](/tools/reference/workbench/update_metadata) | Updates the plan draft's top-level fields. |
| [`workbench__add_step`](/tools/reference/workbench/add_step) | Adds one top-level step to the plan draft. |
| [`workbench__update_step`](/tools/reference/workbench/update_step) | Updates one top-level step in the plan draft. |
| [`workbench__delete_step`](/tools/reference/workbench/delete_step) | Removes one top-level step from the plan draft. |
| [`workbench__restore_draft`](/tools/reference/workbench/restore_draft) | Undoes the last replacement of the plan draft. |
| [`workbench__describe_tool`](/tools/reference/workbench/describe_tool) | Describes one catalog tool without calling it. |
| [`workbench__read_file`](/tools/reference/workbench/read_file) | Reads a text file from the project directory. |
| [`workbench__glob`](/tools/reference/workbench/glob) | Finds files in the project directory by glob pattern. |
| [`workbench__grep`](/tools/reference/workbench/grep) | Searches file contents in the project directory with a regular expression. |
