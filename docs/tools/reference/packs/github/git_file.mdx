## Behavior

- Reads the file as it exists at `ref`, not the working copy.
- Truncates to a byte budget. A truncated file ends with a `[file truncated: …]` line.

| Pack | Kind | Effect |
| --- | --- | --- |
| [`github`](/tools/reference/packs/github): add `"github"` to `[tools].packs` | `exec` | Read-only |

## Input

<ParamField body="ref" type="string" required>
  Ref or commit sha (e.g. the PR head sha)
</ParamField>

<ParamField body="path" type="string" required>
  File path within the repository
</ParamField>

<ParamField body="max_bytes" type="integer" default="200000">
  Truncate the content to this many bytes (a marker line flags truncation)
</ParamField>
