## Behavior

- Covers `base..head`: what landed since `base`.
- Excludes merge commits unless you set `include_merges`.
- Parses the pull request number from a trailing `(#123)` in each subject.
- An empty range returns `count: 0`, not an error.

| Pack | Kind | Effect |
| --- | --- | --- |
| [`github`](/tools/reference/packs/github): add `"github"` to `[tools].packs` | `exec` | Read-only |

## Input

<ParamField body="base" type="string" required>
  Ref or sha the range starts after (exclusive) — e.g. the previous release tag from gh_release's previous_tag.
</ParamField>

<ParamField body="head" type="string" default="HEAD">
  Ref or sha the range ends at (inclusive); e.g. the release tag
</ParamField>

<ParamField body="paths" type="string" default="">
  Space-separated pathspecs scoping the log; "" for everything
</ParamField>

<ParamField body="max_commits" type="integer" default="200">
  Cap on returned commits (truncated flags the cut; total always counts the whole range)
</ParamField>

<ParamField body="include_merges" type="boolean" default="false">
  Keep merge commits. Default false — on a squash-merge history merges are noise, and on a merge-commit history the merge subject duplicates the branch it brought in.
</ParamField>

## Output

<ResponseField name="commits" type="object[]">
  Newest first
</ResponseField>

<ResponseField name="commits.[].sha" type="string">
  Full commit sha
</ResponseField>

<ResponseField name="commits.[].short_sha" type="string">
  Abbreviated sha
</ResponseField>

<ResponseField name="commits.[].author" type="string">
  Author name
</ResponseField>

<ResponseField name="commits.[].date" type="string">
  Author date
</ResponseField>

<ResponseField name="commits.[].subject" type="string">
  First line of the commit message
</ResponseField>

<ResponseField name="commits.[].pr" type="integer | null">
  PR number from a trailing "(#123)"
</ResponseField>

<ResponseField name="count" type="integer">
  Commits returned
</ResponseField>

<ResponseField name="total" type="integer">
  Commits in the whole range
</ResponseField>

<ResponseField name="truncated" type="boolean">
  true when max_commits cut the list
</ResponseField>
