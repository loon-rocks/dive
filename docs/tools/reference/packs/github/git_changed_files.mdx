## Behavior

- Uses the merge-base diff, filtered to a path prefix.
- Each change has a `status`: `added`, `modified`, `deleted`, `renamed`, `copied` or `type_changed`.
- Deleted files don't exist at the head ref. Filter them out before reading files with `git_file`.
- No changes returns `count: 0`, not an error.

| Pack | Kind | Effect |
| --- | --- | --- |
| [`github`](/tools/reference/packs/github): add `"github"` to `[tools].packs` | `exec` | Read-only |

## Input

<ParamField body="base" type="string" required>

<ParamField body="head" type="string" required>

</ParamField>

<ParamField body="prefix" type="string" required>
  Path prefix filter; "" matches every file
</ParamField>
