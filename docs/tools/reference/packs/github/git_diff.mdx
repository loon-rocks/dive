## Behavior

- Uses the merge-base diff (`base...head`), optionally scoped to paths.
- Truncates to a byte budget. A truncated diff ends with a `[diff truncated: …]` line.

| Pack | Kind | Effect |
| --- | --- | --- |
| [`github`](/tools/reference/packs/github): add `"github"` to `[tools].packs` | `exec` | Read-only |

## Input

<ParamField body="base" type="string" required>
  Base ref or commit sha
</ParamField>

<ParamField body="head" type="string" required>
  Head ref or commit sha
</ParamField>

<ParamField body="paths" type="string" required>
  Space-separated pathspecs; "." for everything
</ParamField>

<ParamField body="exclude" type="string" required>
  Space-separated paths to exclude; "" for none
</ParamField>

<ParamField body="max_bytes" type="integer" required>
  Truncate the diff to this many bytes (a marker line flags truncation)
</ParamField>
