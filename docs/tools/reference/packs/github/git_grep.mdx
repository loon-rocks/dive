## Behavior

- Uses POSIX extended regex, optionally scoped to pathspecs.
- Caps results at `max_matches`; `truncated` flags the cut.
- No match returns `count: 0`, not an error.

| Pack | Kind | Effect |
| --- | --- | --- |
| [`github`](/tools/reference/packs/github): add `"github"` to `[tools].packs` | `exec` | Read-only |

## Input

<ParamField body="pattern" type="string" required>
  POSIX extended regex to search for
</ParamField>

<ParamField body="ref" type="string" default="HEAD">
  Ref or commit sha to search at
</ParamField>

<ParamField body="paths" type="string" default="">
  Space-separated pathspecs scoping the search; "" for everything
</ParamField>

<ParamField body="max_matches" type="integer" default="200">
  Cap on returned matches (truncated flags the cut)
</ParamField>
