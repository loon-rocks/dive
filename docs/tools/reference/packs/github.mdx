Enable it with `packs = ["github"]` under `[tools]` in config.toml.

## Requirements

- `git`, `jq` and `gh` on your `PATH`.
- `GH_TOKEN`, or `gh auth login`, for the `gh_*` tools.
- A checkout whose `origin` points at the repository.

## Tools

| Name | Description |
| --- | --- |
| [`builtin__git_log`](/tools/reference/packs/github/git_log) | Lists the commits between two git refs, newest first. |
| [`builtin__git_diff`](/tools/reference/packs/github/git_diff) | Returns the unified diff between two git refs. |
| [`builtin__git_changed_files`](/tools/reference/packs/github/git_changed_files) | Lists the files changed between two git refs, with per-file status and line counts. |
| [`builtin__git_file`](/tools/reference/packs/github/git_file) | Returns a file's contents at a git ref. |
| [`builtin__git_grep`](/tools/reference/packs/github/git_grep) | Searches tracked files at a git ref with a regular expression. |
| [`builtin__gh_pr_meta`](/tools/reference/packs/github/gh_pr_meta) | Returns a pull request's title, body, state, author and base and head commits. |
| [`builtin__gh_pr_ticket`](/tools/reference/packs/github/gh_pr_ticket) | Finds a ticket identifier, such as `LN-1234`, in a pull request. |
| [`builtin__gh_pr_comment`](/tools/reference/packs/github/gh_pr_comment) | Posts or updates a comment on a pull request. |
| [`builtin__gh_pr_inline_comments`](/tools/reference/packs/github/gh_pr_inline_comments) | Posts inline review comments on a pull request's diff. |
| [`builtin__gh_pr_review_threads`](/tools/reference/packs/github/gh_pr_review_threads) | Lists the review threads a plan posted on a pull request, as structured findings. |
| [`builtin__gh_pr_thread_sync`](/tools/reference/packs/github/gh_pr_thread_sync) | Syncs a plan's inline review threads on a pull request. |
| [`builtin__gh_release`](/tools/reference/packs/github/gh_release) | Returns a release's tag, title, notes and date, plus the previous release's tag. |
