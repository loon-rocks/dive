`merged_prs` lists the pull requests merged since a date by running the `gh` CLI.

<RequestExample>

```yaml .graph/tools/merged_prs.yaml
name: merged_prs
description: Pull requests merged into this repository since a date, as number, title and merge time.
kind: exec
command: gh
args:
  - pr
  - list
  - --state
  - merged
  - --search
  - "merged:>={{input.since}}"
  - --json
  - number,title,mergedAt
read_only: true
input_schema:
  type: object
  required: [since]
  properties:
    since:
      type: string
      description: The earliest merge date, as YYYY-MM-DD
```

</RequestExample>

<Steps>
  <Step title="Open the workbench in tool mode">
    ```bash
    graph workbench tool
    ```
  </Step>
  <Step title="Describe the tool">
    Say what goes in, what comes back, and which command or API it uses. The drafter checks your catalog for a tool that already does it, then puts a first draft in the pane and asks what it can't settle itself.

    <Frame caption="The tool drafter's first draft in the pane, with its question in the chat.">
      <img src="/images/workbench/tool-drafting.svg" alt="The workbench with tool_drafter active: the request and the drafter's question on the left, and the merged_prs draft on the right with its description, kind exec, the gh command it runs, its since input, and no problems." />
    </Frame>
  </Step>
  <Step title="Test-run it">
    Answer its questions and ask it to test the tool. It runs the draft on a sample input once you approve the run:

    <Frame caption="The approval form for a test run, showing the command and the sample input.">
      <img src="/images/workbench/tool-try.svg" alt="The workbench's approval form asking whether to test-run user__merged_prs once with the command gh pr list --state merged --search merged:>={{input.since}} --json number,title,mergedAt and the input since 2026-09-24, with run set to true." />
    </Frame>

    The result shows in the pane:

    ```json
    [
      {
        "mergedAt": "2026-10-09T02:25:01Z",
        "number": 147,
        "title": "feat!: plans state how they finish with a required finish key…"
      },
      {
        "mergedAt": "2026-10-08T19:34:56Z",
        "number": 146,
        "title": "feat!: workbench agents work on plans through the same artifact tools…"
      },
      …
    ]
    ```
  </Step>
  <Step title="Save">
    Press <kbd>Ctrl</kbd>+<kbd>S</kbd>. graph writes the file to `./.graph/tools/merged_prs.yaml`, and the tool is in your catalog as `user__merged_prs`.
  </Step>
</Steps>
