This repository's dive config needs a change for graph v0.16.0 if any config file lists `github` or `slack` in `[tools].packs`. If none does, report that and change nothing: graph reads older config files as they are.

**What changed:** The `github` and `slack` tools are no longer built into graph. They install as packs, and config version 4 replaces `[tools].packs = [...]` with one `[packs.<name>]` entry per installed pack. graph refuses to load a config whose pack entry isn't installed, and names the pack.

**Steps:**

1. Run `dive config check` to see each config file's version.
2. Run `dive config migrate`, and `dive config migrate --global` if a global config exists. Do not hand-edit the result. Read the notes it prints.
3. For every `[packs.<name>]` entry the migration wrote, run `dive pack add <name>`, adding `--global` for an entry in the global config.
4. Commit `.dive/config.toml`, `.dive/packs/` and `.dive/packs.lock`. If `.gitignore` ignores `.dive/`, let `.dive/packs/` and `.dive/packs.lock` through.
5. Run `dive config check` again and confirm it loads and lists each pack as matching `packs.lock`.
6. If a CI workflow pins `ghcr.io/loon-rocks/dive:vX.Y.Z`, move the pin to `v0.16.0` in the same change. Older images refuse config version 4.

**Report back:** which config files you migrated, the notes `dive config migrate` printed, which packs you installed, and whether any image pin moved.
