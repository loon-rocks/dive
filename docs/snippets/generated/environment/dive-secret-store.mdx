<ParamField header="DIVE_SECRET_STORE" type="enum<string>" default="os">
  Whether `${NAME}` references read the OS credential store when the environment doesn't set `NAME`.

  | Value | Effect |
  | --- | --- |
  | `os` | Read the macOS Keychain, or the Secret Service on Linux, under service `dive`. Where neither is available, graph reads the environment only. |
  | `none` | Read the environment only. |

</ParamField>
