<ParamField body="project" type="object">
  This project's identity. Belongs in the project config.
</ParamField>

<ParamField body="project.id" type="string">
  An id Dive generates the first time you store a project secret with `dive secret set NAME --project`. Project secrets are keyed by it, so renaming or moving the folder keeps them. Letters, digits and hyphens.
</ParamField>

<ParamField body="project.isolate" type="boolean" default="false">
  When `true`, this project reads nothing from `~/.config/dive`, so its `.dive/config.toml` must define everything it uses. See [Isolated projects](/reference/configuration#isolated-projects).
</ParamField>
