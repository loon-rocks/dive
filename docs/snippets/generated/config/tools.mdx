<ParamField body="tools" type="object">
  Where tools come from.
</ParamField>

<ParamField body="tools.paths" type="string[]" default="- ./.dive/tools
- ~/.config/dive/tools">
  Tool directories, searched in order. New tools are saved to the first one. In the global workspace (`~/.config/dive`), relative entries such as `./.dive/tools` are skipped.
</ParamField>

<ParamField body="tools.always_loaded" type="string[]" default="- builtin__infer
- builtin__reshape
- builtin__flatten
- builtin__dedupe
- builtin__sort
- builtin__take
- builtin__rank
- builtin__save_file
- builtin__read_file">
  Tools offered up front, never deferred behind a search. Plan drafting always offers them, and an agent gets the ones its `tools` list matches.
</ParamField>
