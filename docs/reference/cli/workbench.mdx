Opens the full-screen workbench. With no subcommand it starts at the front desk, which asks what you want to build. Needs an interactive terminal on stdin and stdout.

The workbench logs to `<data_dir>/workbench.log` instead of stderr. Set `[workbench].log_path` or `DIVE_WORKBENCH_LOG` to change the path.

Alias: `dive wb`.

## Available commands

- [`dive workbench plan`](/reference/cli/workbench/plan): Open the workbench in plan mode: draft a new plan, or open an existing one to inspect, edit and run — fully, or gated with per-tool-call confirmation
- [`dive workbench agent`](/reference/cli/workbench/agent): Open the workbench in agent mode: draft a new agent, or edit an existing one
- [`dive workbench tool`](/reference/cli/workbench/tool): Open the workbench in tool mode: draft a new user tool, or edit an existing one
