Writes a commented starter config to `./.dive/config.toml`, or to `~/.config/dive/config.toml` with `--global`. Refuses to overwrite an existing file unless `--force` is set.

## Options

<ParamField query="--global" type="boolean">
  Write to the global location (~/.config/dive/) instead of the project (./.dive/)
</ParamField>

<ParamField query="--force" type="boolean">
  Overwrite an existing file
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive config init [OPTIONS]
```

```bash Example 1
dive config init
```

```bash Example 2
dive config init --global
```

</RequestExample>
