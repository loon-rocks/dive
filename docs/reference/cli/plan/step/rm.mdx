Removes a step. The edit is refused while a later step still references it.

## Arguments

<ParamField path="NAME|PATH" type="string" required>
  The plan's identifier or YAML file path
</ParamField>

<ParamField path="ID" type="string" required>
  The step's id
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
graph plan step rm [OPTIONS] <NAME|PATH> <ID>
```

```bash Example
graph plan step rm weekly_changes E2
```

</RequestExample>
