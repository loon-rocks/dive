Renames a step and rewrites every reference to it in later steps, the `output` map and the `solver` templates.

## Arguments

<ParamField path="NAME|PATH" type="string" required>
  The plan's identifier or YAML file path
</ParamField>

<ParamField path="ID" type="string" required>
  The step's id
</ParamField>

<ParamField path="NEW_ID" type="string" required>
  The new step id
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
graph plan step rename [OPTIONS] <NAME|PATH> <ID> <NEW_ID>
```

```bash Example
graph plan step rename weekly_changes E1 commits
```

</RequestExample>
