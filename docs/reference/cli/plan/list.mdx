Lists the plan catalog, one plan per line: identifier, name, and scope (`project`, `global`, the pack, or `built-in`). A plan that [can't run here](/plans/overview#plans-that-cant-run-here) gets a fourth column, `missing: <item>`, naming the first thing it's missing. `--json` gives every plan a `scope` and a `missing` array, and reports plans that failed to load under `skipped`.

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<ParamField query="--identity" type="string">
  Act as this [identities] entry: runs get a run token minted for its tenant and user, which http tools send to the app

  Format: `IDENTITY`.
</ParamField>
