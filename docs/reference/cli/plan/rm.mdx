Deletes the file holding the plan, without asking. A plan file that replaces a built-in plan reverts it to the shipped version, and one that shadows a copy in a later plans directory hands over to that copy. Plans and agents that still call it are listed; nothing else is changed. Built-in and pack plans can't be removed one at a time — remove a pack with `dive pack remove`.

## Arguments

<ParamField path="NAME" type="string" required>
  The plan's identifier
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive plan rm [OPTIONS] <NAME>
```

```bash Example 1
dive plan rm weekly_changes
```

```bash Example 2
dive plan rm compose_plan --json
```
