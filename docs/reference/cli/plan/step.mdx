## Available commands

- [`dive plan step add`](/reference/cli/plan/step/add): Append a step, or anchor it before/after an existing one
- [`dive plan step update`](/reference/cli/plan/step/update): Set one attribute of a step
- [`dive plan step rename`](/reference/cli/plan/step/rename): Rename a step, rewriting every downstream &#123;&#123;id.*&#125;&#125; reference
- [`dive plan step unset`](/reference/cli/plan/step/unset): Clear one optional attribute of a step
- [`dive plan step rm`](/reference/cli/plan/step/rm): Remove a step
