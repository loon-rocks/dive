## Available commands

- [`graph tool list`](/reference/cli/tool/list): List every tool visible to the agent and planner
- [`graph tool show`](/reference/cli/tool/show): Show one tool's description and schemas
- [`graph tool test`](/reference/cli/tool/test): Invoke a tool directly
- [`graph tool migrate`](/reference/cli/tool/migrate): Rewrite a user tool file to the current tool format
