## Available commands

- [`dive tool list`](/reference/cli/tool/list): List every tool visible to the agent and planner
- [`dive tool show`](/reference/cli/tool/show): Show one tool's description and schemas
- [`dive tool test`](/reference/cli/tool/test): Invoke a tool directly
- [`dive tool rm`](/reference/cli/tool/rm): Delete a user tool file or a built-in tool's override
- [`dive tool migrate`](/reference/cli/tool/migrate): Rewrite a user tool file to the current tool format

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
