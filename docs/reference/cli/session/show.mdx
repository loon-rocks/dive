## Arguments

<ParamField path="ID" type="string" required>
  The session id, as `dive session list` prints it
</ParamField>

## Options

<ParamField query="--state" type="boolean">
  Include the full runtime state
</ParamField>

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<ParamField query="--identity" type="string">
  Act as this [identities] entry: runs get a run token minted for its tenant and user, which http tools send to the app

  Format: `IDENTITY`.
</ParamField>

<RequestExample>

```bash Usage
dive session show [OPTIONS] <ID>
```

```bash Example 1
dive session show 4f1c9a2b7d3e
```

```bash Example 2
dive session show 4f1c9a2b7d3e --state --json
```

</RequestExample>
