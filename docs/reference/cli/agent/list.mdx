Prints each agent's name, source, description and scope (`project`, `global`, `pack` or `built-in`). An agent that [can't run here](/plans/overview#plans-that-cant-run-here) gets a final column, `missing: <item>`. `--json` adds its model, subagents, handoffs, how it is called as a subagent (`subagentIo`), its `scope`, a `missing` array with the path to each missing item, and any files that failed to load (`loadErrors`).

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<ParamField query="--identity" type="string">
  Act as this [identities] entry: runs get a run token minted for its tenant and user, which http tools send to the app

  Format: `IDENTITY`.
</ParamField>
