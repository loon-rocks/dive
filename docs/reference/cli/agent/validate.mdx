Problems exit 1. `--json` lists them under `problems`.

## Arguments

<ParamField path="PATH" type="string">
  One agent file to check against the others; omit to check every agent
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
graph agent validate [OPTIONS] [PATH]
```

```bash Example 1
graph agent validate
```

```bash Example 2
graph agent validate .graph/agents/release_notes.yaml
```

</RequestExample>
