Rewrites one agent file to the current agent file version.

## Arguments

<ParamField path="PATH" type="string" required>
  Path to the agent file
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive agent migrate [OPTIONS] <PATH>
```

```bash Example
dive agent migrate .dive/agents/release_notes.yaml
```

</RequestExample>
