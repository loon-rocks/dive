Deletes the file defining the agent, without asking. A project agent that shadows a global one hands over to it, and an agent file that replaces a built-in agent reverts it to the shipped version. Plans and agents that still call it, hand off to it or run it as a subagent are listed; nothing else is changed. Pack agents can't be removed one at a time — remove a pack with `dive pack remove`.

## Arguments

<ParamField path="NAME" type="string" required>
  The agent's name
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive agent rm [OPTIONS] <NAME>
```

```bash Example 1
dive agent rm release_notes
```

```bash Example 2
dive agent rm chat --json
```

</RequestExample>
