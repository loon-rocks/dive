Prints the binary version and the version each kind of file is written at. `--json` also reports, under `fileVersions`, the oldest version of each the binary still reads. `dive --version` prints the same lines.

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive version [OPTIONS]
```

```bash Example 1
dive version
```

```bash Example 2
dive version --json
```

</RequestExample>
