## Available commands

- [`graph pack add`](/reference/cli/pack/add): Install a pack from git as a plain copy in the project, global or given graph directory
- [`graph pack list`](/reference/cli/pack/list): List installed packs with their tags, newer releases, local edits and shadowing
- [`graph pack update`](/reference/cli/pack/update): Move packs to the newest release their ref allows, within the current major
- [`graph pack remove`](/reference/cli/pack/remove): Delete a pack's copy, config entry and lock entry, and list files that still call it

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
