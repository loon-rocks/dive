## Available commands

- [`graph pack add`](/reference/cli/pack/add): Install a pack from git as a plain copy in the project, global or given graph directory
- [`graph pack list`](/reference/cli/pack/list): List installed packs with their tags, newer releases, local edits and shadowing
- [`graph pack update`](/reference/cli/pack/update): Move packs to the newest release their ref allows, or with --major across majors, migrating your files at each
- [`graph pack remove`](/reference/cli/pack/remove): Delete a pack's copy, config entry and lock entry, and list files that still call it
- [`graph pack new`](/reference/cli/pack/new): Scaffold a pack in a directory of a packs repository: manifest, one tool, plan and agent, README, CHANGELOG and MIGRATING.md
- [`graph pack check`](/reference/cli/pack/check): Load a pack the way an install would and report every problem: manifest, files, references, names, migrations and requirements
- [`graph pack run`](/reference/cli/pack/run): Run one of a pack's items, private and migration ones included, under its manifest name
- [`graph pack test`](/reference/cli/pack/test): Run check, then every migration over its sample files in tests/migrations/v&lt;N&gt;/ and validate the result
- [`graph pack release`](/reference/cli/pack/release): Compare the public interface with the previous release tag and create the next annotated tag, without pushing
