Lists the names referenced by the global and project config.toml, user tools, installed packs' tools, and packs' `requires.env`. Each name's source is the first of `env`, `project` and `shared` that sets it, followed by the sources it shadows, or `missing`. The OS credential store can't be enumerated, so a stored name nothing references isn't listed. Values are never printed.

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>
