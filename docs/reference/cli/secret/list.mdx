Lists the names referenced by the global and project config.toml, user tools, installed packs' tools, and packs' `requires.env`. Each name's source is the first of `env`, `project` and `shared` that sets it, followed by the sources it shadows, or `missing`. Names stored in the OS credential store for this project or for every project are listed too, even when nothing references them. A name a tool's `env` describes (`{value, description}`) shows its description below it. Values are never printed.

  Print a JSON envelope instead of text
</ParamField>
