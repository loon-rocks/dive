Prints the environment, project and shared values in resolution order, marks the one in use, and lists the references. Values are masked to their last 4 characters, and to nothing when shorter than 8.

## Arguments

<ParamField path="NAME" type="string" required>
  The variable name, as `${NAME}` references it
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
graph secret show [OPTIONS] <NAME>
```

```bash Example
graph secret show ANTHROPIC_API_KEY
```

</RequestExample>
