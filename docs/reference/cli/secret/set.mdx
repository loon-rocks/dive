Reads the value with hidden input when stdin is a terminal, or from stdin when it is piped; one trailing newline is dropped. The value is never accepted as an argument, where it would land in shell history. Storing a name again replaces its value. When the environment also sets the name, the environment's value still wins.

## Arguments

<ParamField path="NAME" type="string" required>
  The variable name, as `${NAME}` references it
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
graph secret set [OPTIONS] <NAME>
```

```bash Example 1

```

```bash Example 2
printf %s "$TOKEN" | graph secret set GITHUB_TOKEN
```
