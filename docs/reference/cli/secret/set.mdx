Reads the value with hidden input when stdin is a terminal, or from stdin when it is piped; one trailing newline is dropped. The value is never accepted as an argument, where it would land in shell history. Storing a name again replaces its value.

Without --project the value is shared by every project on this machine. With --project it applies only to this project, keyed by the `[project] id` in .dive/config.toml, which is generated on first use. A name resolves from the environment first, then this project's value, then the shared value.

## Arguments

<ParamField path="NAME" type="string" required>
  The variable name, as `${NAME}` references it
</ParamField>

## Options

<ParamField query="--project" type="boolean">
  Store the value for this project only
</ParamField>

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive secret set [OPTIONS] <NAME>
```

```bash Example 1
dive secret set ANTHROPIC_API_KEY
```

```bash Example 2
dive secret set SLACK_BOT_TOKEN --project
```

```bash Example 3
printf %s "$TOKEN" | dive secret set GITHUB_TOKEN
```

</RequestExample>
