Removes the shared value, or this project's value with --project. Removing a name that isn't stored is refused and exits 1.

## Arguments

<ParamField path="NAME" type="string" required>
  The variable name, as `${NAME}` references it
</ParamField>

## Options

<ParamField query="--project" type="boolean">
  Remove this project's value instead of the shared one
</ParamField>

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive secret rm [OPTIONS] <NAME>
```

```bash Example 1
dive secret rm GITHUB_TOKEN
```

```bash Example 2
dive secret rm SLACK_BOT_TOKEN --project
```

</RequestExample>
