## Available commands

- [`dive session list`](/reference/cli/session/list): List sessions
- [`dive session show`](/reference/cli/session/show): Show a session's runs and messages
- [`dive session rm`](/reference/cli/session/rm): Delete a session

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<ParamField query="--identity" type="string">
  Act as this [identities] entry: runs get a run token minted for its tenant and user, which http tools send to the app

  Format: `IDENTITY`.
</ParamField>
