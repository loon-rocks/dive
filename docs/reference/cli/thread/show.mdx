## Arguments

<ParamField path="ID" type="string" required>
  The thread id, as `graph thread list` prints it
</ParamField>

## Options

<ParamField query="--state" type="boolean">
  Include the full runtime state
</ParamField>

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
graph thread show [OPTIONS] <ID>
```

```bash Example 1
graph thread show 4f1c9a2b7d3e
```

```bash Example 2
graph thread show 4f1c9a2b7d3e --state --json
```

</RequestExample>
