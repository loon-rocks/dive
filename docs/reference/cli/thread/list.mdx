Lists the threads started in the current directory's project, or the global threads when the directory has no `.dive` folder. `--all` lists every thread.

## Options

<ParamField query="--all" type="boolean">
  List every thread, whatever project it was started in
</ParamField>

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive thread list [OPTIONS]
```

```bash Example 1
dive thread list
```

```bash Example 2
dive thread list --all
```

</RequestExample>
