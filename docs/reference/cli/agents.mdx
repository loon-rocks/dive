## Available commands

- [`graph agents list`](/reference/cli/agents/list): List every agent: built-in, global (~/.config/graph/agents), and project (./.graph/agents)
- [`graph agents show`](/reference/cli/agents/show): Print an agent's effective definition, the file to copy when customizing it
- [`graph agents validate`](/reference/cli/agents/validate): Validate every agent, or one agent file against the others
- [`graph agents migrate`](/reference/cli/agents/migrate): Rewrite an agent file to the current agent format

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
