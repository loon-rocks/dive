## Available commands

- [`dive agent list`](/reference/cli/agent/list): List every agent: built-in, global (~/.config/dive/agents), and project (./.dive/agents)
- [`dive agent show`](/reference/cli/agent/show): Print an agent's effective definition, the file to copy when customizing it
- [`dive agent validate`](/reference/cli/agent/validate): Validate every agent, or one agent file against the others
- [`dive agent rm`](/reference/cli/agent/rm): Delete an agent file
- [`dive agent migrate`](/reference/cli/agent/migrate): Rewrite an agent file to the current agent format
