## Available commands

- [`dive mcp list`](/reference/cli/mcp/list): List configured servers and their status
- [`dive mcp tools`](/reference/cli/mcp/tools): List tools exposed by servers
- [`dive mcp test`](/reference/cli/mcp/test): Connect to a server and verify initialize + tools/list
- [`dive mcp serve`](/reference/cli/mcp/serve): Serve Dive's plans and authoring commands to an agent over MCP (stdio)
- [`dive mcp login`](/reference/cli/mcp/login): Sign in to a server that uses OAuth, in your browser
- [`dive mcp logout`](/reference/cli/mcp/logout): Remove a saved sign-in
- [`dive mcp probe`](/reference/cli/mcp/probe): Pre-warm the observed-shape cache by invoking read-only tools
