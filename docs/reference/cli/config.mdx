## Available commands

- [`dive config show`](/reference/cli/config/show): Print the merged effective configuration
- [`dive config init`](/reference/cli/config/init): Write a starter config file
- [`dive config path`](/reference/cli/config/path): Print the config file locations and which exist
- [`dive config check`](/reference/cli/config/check): Report each config file's format and whether the merged config loads
- [`dive config migrate`](/reference/cli/config/migrate): Rewrite a config file to the current config format, comments intact
