## Available commands

- [`graph config show`](/reference/cli/config/show): Print the merged effective configuration
- [`graph config init`](/reference/cli/config/init): Write a starter config file
- [`graph config path`](/reference/cli/config/path): Print the config file locations and which exist
- [`graph config check`](/reference/cli/config/check): Report each config file's format and whether the merged config loads
- [`graph config migrate`](/reference/cli/config/migrate): Rewrite a config file to the current config format, comments intact
