## Available commands

- [`graph tools list`](/reference/cli/tools/list): List every tool visible to the agent and planner
- [`graph tools show`](/reference/cli/tools/show): Show one tool's description and schemas
- [`graph tools test`](/reference/cli/tools/test): Invoke a tool directly
- [`graph tools migrate`](/reference/cli/tools/migrate): Rewrite a user tool file to the current tool format
