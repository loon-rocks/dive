A command-line agent with a plan-based execution engine

```bash
dive [OPTIONS] <COMMAND>
```

## Global options

These options work with every command.

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>
