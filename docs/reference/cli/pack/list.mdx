## Options

<ParamField query="--global" type="boolean">
  Target the global layer (~/.config/dive/) instead of the project's ./.dive/
</ParamField>

<ParamField query="--dir" type="string">
  Target this Dive directory, laid out like .dive/ (config.toml, packs/, packs.lock)

  Format: `PATH`.
</ParamField>

<ParamField query="--offline" type="boolean">
  Skip the git ls-remote per pack and the columns it fills
</ParamField>

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

```bash Usage
dive pack list [OPTIONS]
```
