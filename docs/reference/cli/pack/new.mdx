Writes the files from a scaffold built into Dive, so it works offline, into &lt;PATH&gt;/&lt;NAME&gt;/, which is created when missing and refused when it holds anything. A packs repository holds one pack per directory, each released as `<NAME>/vX.Y.Z` tags. When the repository has no `.github/workflows/packs.yaml`, it also gets one that runs `dive pack test` over every pack, and a `.gitignore` for `.dive/` when it has none. The scaffold passes `dive pack check` and `dive pack test` as written.

## Arguments

<ParamField path="NAME" type="string" required>
  The pack's name, written into pack.toml and used as its directory: lowercase letters, digits and underscores, at most 20 characters
</ParamField>

<ParamField path="PATH" type="string" default=".">
  The packs repository's root; the pack goes in &lt;PATH&gt;/&lt;NAME&gt;/
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>
