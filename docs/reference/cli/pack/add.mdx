## Arguments

<ParamField path="NAME|URL" type="string" required>
  A bare name (the &lt;name&gt; directory of github.com/tylerdavis/graph-packs) or a git URL; a name already in [packs] installs that entry
</ParamField>

## Options

<ParamField query="--path" type="string">
  The pack's directory inside the repository, whose releases are the tags &lt;DIR&gt;/vX.Y.Z; default: the repository root (a bare name's own directory)

  Format: `DIR`.
</ParamField>

<ParamField query="--as" type="string">
  Install under this name instead of the manifest's

  Format: `NAME`.
</ParamField>

<ParamField query="--ref" type="string">
  A major line (v2), an exact release (v2.1.0, pinned) or a branch; default: the newest release

  Format: `REF`.
</ParamField>

<ParamField query="--global" type="boolean">
  Target the global layer (~/.config/graph/) instead of the project's ./.graph/
</ParamField>

<ParamField query="--dir" type="string">
  Target this graph directory, laid out like .graph/ (config.toml, packs/, packs.lock)

  Format: `PATH`.
</ParamField>

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
graph pack add [OPTIONS] <NAME|URL>
```

</RequestExample>
