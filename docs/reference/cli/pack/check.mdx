Loads the pack under its manifest name and checks every plan and agent against the pack plus Dive's built-ins, including each step's literal input against the called tool's input schema. pack.toml must list the systems the pack runs on in `requires.os` (`macos`, `linux`). Calls to MCP servers named in `requires.mcp` are checked against the server when one is configured under that name, and reported as unchecked otherwise. A directory without pack.toml is a packs repository: every immediate subdirectory holding one is checked. Exits 1 when there is any problem.

## Arguments

<ParamField path="PATH" type="string" default=".">
  The pack's directory, holding pack.toml, or a packs repository whose subdirectories hold packs
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive pack check [OPTIONS] [PATH]
```

```bash Example 1
dive pack check
```

```bash Example 2
dive pack check files --json
```

</RequestExample>
