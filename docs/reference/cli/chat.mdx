Starts a conversation with the default `chat` agent or the named one. A resumed session continues with its active agent; naming an agent other than the one the session started with is refused.

Slash commands: `/agent` lists agents and marks the active one, `/agent <name>` switches to another from the next message, `/session` and `/state` print the current session and its state, and `/quit` exits.

## Arguments

<ParamField path="AGENT" type="string">
  The agent to talk to; the default `chat` agent when omitted
</ParamField>

## Options

<ParamField query="--session" type="string">
  Continue a session: `--session <id>` for a specific one, bare `--session` for the most recent chat. Omit to start a new session

  Format: `SESSION`.

  The value is optional: `--session` on its own is accepted.
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<ParamField query="--identity" type="string">
  Act as this [identities] entry: runs get a run token minted for its tenant and user, which http tools send to the app

  Format: `IDENTITY`.
</ParamField>

<RequestExample>

```bash Usage
dive chat [OPTIONS] [AGENT]
```

```bash Example 1
dive chat
```

```bash Example 2

```

```bash Example 3
dive chat --session
```

</RequestExample>
