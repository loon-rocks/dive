## Available commands

- [`graph secret set`](/reference/cli/secret/set): Store a secret in the OS credential store
- [`graph secret rm`](/reference/cli/secret/rm): Remove a secret from the OS credential store
- [`graph secret list`](/reference/cli/secret/list): List every variable name the config, tools and packs reference, and where each resolves from
- [`graph secret show`](/reference/cli/secret/show): Show where one name resolves from and what references it
