## Available commands

- [`dive secret set`](/reference/cli/secret/set): Store a secret in the OS credential store
- [`dive secret rm`](/reference/cli/secret/rm): Remove a secret from the OS credential store
- [`dive secret list`](/reference/cli/secret/list): List every variable name the config, tools and packs reference, and where each resolves from
- [`dive secret show`](/reference/cli/secret/show): Show where one name resolves from and what references it
