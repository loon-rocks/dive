For a `builtin__`, `user__` or pack tool, also names its source on stderr: the tool file's path, `built-in`, or `pack <name> <tag> (<layer>)`. `--json` prints the whole definition, including `inputSchema`, with absent keys as `null`.

## Arguments

<ParamField path="NAME" type="string" required>
  The tool's namespaced name, as `graph tool list` prints it
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
graph tool show [OPTIONS] <NAME>
```

```bash Example 1
graph tool show github__tool__git_log
```

```bash Example 2
graph tool show linear__list_issues --json
```

</RequestExample>
