Rewrites one user tool file to the current tool file version. It takes a path rather than a tool name and doesn't connect to MCP servers.

## Arguments

<ParamField path="PATH" type="string" required>
  Path to the user tool file
</ParamField>

## Options

<ParamField query="--json" type="boolean">
  Print a JSON envelope instead of text
</ParamField>

## Global options

<ParamField query="-v, --verbose" type="integer">
  Increase log verbosity (-v info, -vv debug, -vvv trace)
</ParamField>

<RequestExample>

```bash Usage
dive tool migrate [OPTIONS] <PATH>
```

```bash Example
dive tool migrate .dive/tools/summarize.yaml
```

</RequestExample>
