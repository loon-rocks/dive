## Available commands

- [`dive plan list`](/reference/cli/plan/list): List available plan documents
- [`dive plan show`](/reference/cli/plan/show): Show a plan document
- [`dive plan validate`](/reference/cli/plan/validate): Validate a plan document by name or file path
- [`dive plan rm`](/reference/cli/plan/rm): Delete a plan file
- [`dive plan migrate`](/reference/cli/plan/migrate): Rewrite a plan file to the current plan format
- [`dive plan run`](/reference/cli/plan/run): Run a plan directly (bypasses the agent loop)
- [`dive plan new`](/reference/cli/plan/new): Scaffold an empty plan file to build up with `set` and `step add`
- [`dive plan draft`](/reference/cli/plan/draft): Draft a plan from a goal using the planner model (costs inference)
- [`dive plan set`](/reference/cli/plan/set): Set one plan attribute
- [`dive plan unset`](/reference/cli/plan/unset): Clear one optional plan attribute
- [`dive plan step`](/reference/cli/plan/step): Add, edit, or remove a plan's steps
