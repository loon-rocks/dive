## Result

- `problems`: errors that make `ok` false
- `notes`: issues that keep the plan from running here but don't make it invalid

Mirrors `graph plan validate`.

| Available to | Effect |
| --- | --- |
| MCP clients of `graph mcp serve` | Not marked read-only |

## Input

<ParamField body="target" type="string" required>
  A plan identifier (as in `plan list`) or a path to a plan YAML file.
</ParamField>
