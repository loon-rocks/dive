- To rename a step, use `dive_plan_step_rename`.
- Mirrors `dive plan step update`.

| Available to | Effect |
| --- | --- |
| MCP clients of `dive mcp serve` | Not marked read-only |

## Input

<ParamField body="attribute" type="enum<string>" required>
  Available options: `tool`, `input`, `reasoning`
</ParamField>

<ParamField body="id" type="string" required>
</ParamField>

<ParamField body="target" type="string" required>
  A plan identifier (as in `plan list`) or a path to a plan YAML file.
</ParamField>

<ParamField body="value" type="any" required>
  A string for `tool` and `reasoning`; a JSON object for `input`.
</ParamField>
