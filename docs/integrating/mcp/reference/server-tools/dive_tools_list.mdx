## Result

- Catalog tools by namespaced name: `<server>__<tool>`, `user__<tool>`, `builtin__<tool>`, `plan__<id>`
- Control steps, under the `(control)` source
- No schemas; use `dive_tools_show` for one entry

Mirrors `dive tool list`.

| Available to | Effect |
| --- | --- |
| MCP clients of `dive mcp serve` | Not marked read-only |

## Input

Takes no input.
