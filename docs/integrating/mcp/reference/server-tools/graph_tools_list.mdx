## Result

- Catalog tools by namespaced name: `<server>__<tool>`, `user__<tool>`, `builtin__<tool>`, `plan__<id>`
- Control steps, under the `(control)` source
- No schemas; use `graph_tools_show` for one entry

Mirrors `graph tools list`.

| Available to | Effect |
| --- | --- |
| MCP clients of `graph mcp serve` | Not marked read-only |

## Input

Takes no input.
