## Result

- Every plan, each with its `scope` and a `missing` array that is empty when the plan can run here
- `skipped`: plan files that failed to load

Mirrors `dive plan list`.

| Available to | Effect |
| --- | --- |
| MCP clients of `dive mcp serve` | Not marked read-only |

## Input

Takes no input.
