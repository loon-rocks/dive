- `inputSchema` is what a step's `input` must match.
- Every key is present, `null` when absent.
- Mirrors `dive tool show`.

| Available to | Effect |
| --- | --- |
| MCP clients of `dive mcp serve` | Not marked read-only |

## Input

<ParamField body="name" type="string" required>
  A namespaced tool name, or a control step: exit, ask, agent, route, map, reduce.
</ParamField>
