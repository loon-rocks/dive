## Behavior

- Refused, with the problems it would cause, if the change would break the plan.
- Changing `identifier` writes a new file and reports the old one as `renamedFrom`.
- Mirrors `graph plan set`.

| Available to | Effect |
| --- | --- |
| MCP clients of `graph mcp serve` | Not marked read-only |

## Input

<ParamField body="attribute" type="enum<string>" required>
  Named exactly as it appears in the plan YAML.

  Available options: `name`, `description`, `identifier`, `exemplars`, `requires_servers`, `input_schema`, `solver`, `output`
</ParamField>

<ParamField body="target" type="string" required>
  A plan identifier (as in `plan list`) or a path to a plan YAML file.
</ParamField>

<ParamField body="value" type="any" required>
  A string for scalar attributes; an array of strings for `exemplars` and `requires_servers`; a JSON object for `input_schema`, `solver`, and `output`.
</ParamField>
