Set `DIVE_EVENTS=jsonl` and Dive writes its progress to stderr as one JSON object per line, instead of text for people. stdout still carries only the result, so you can read both from one run:

```bash
DIVE_EVENTS=jsonl dive plan run weekly_changes \
  --input base=v0.15.0 2> events.jsonl
```

The stream covers `dive plan run`, `dive ask` and `dive chat`. Every event has an `event` field naming its type.

## Events

### tool_started

A tool call began.

<ResponseField name="tool" type="string">
  The tool's full name, such as `github__tool__git_log`.
</ResponseField>

<ResponseField name="args" type="object">
  The input the tool was called with, after templates were filled.
</ResponseField>

### tool_finished

A tool call ended.

<ResponseField name="tool" type="string">
  The tool's full name.
</ResponseField>

<ResponseField name="ms" type="integer">
  How long the call took, in milliseconds.
</ResponseField>

<ResponseField name="is_error" type="boolean">
  Whether the tool returned an error.
</ResponseField>

### agent_round

An agent, or an `agent` step, started another round of model calls and tool calls.

<ResponseField name="n" type="integer">
  The round number.
</ResponseField>

### synthesizing

A plan's `solver` started writing its answer.

### model_call

A model call finished.

<ResponseField name="kind" type="enum<string>">
  `chat` for a chat model, `decision` for a decision model.
</ResponseField>

<ResponseField name="site" type="string">
  Where the call was made: the step's path, such as `E3` or `triage/E1`, or the model role when the call belongs to no step.
</ResponseField>

<ResponseField name="model" type="string">
  The model id.
</ResponseField>

<ResponseField name="input_tokens" type="integer">
  Uncached input tokens.
</ResponseField>

<ResponseField name="output_tokens" type="integer">
  Output tokens.
</ResponseField>

<ResponseField name="cache_creation_input_tokens" type="integer">
  Input tokens written to the provider's prompt cache.
</ResponseField>

<ResponseField name="cache_read_input_tokens" type="integer">
  Input tokens read from the provider's prompt cache.
</ResponseField>

<ResponseField name="ms" type="integer">
  How long the call took, in milliseconds.
</ResponseField>

### usage_summary

What the whole run spent, sent once at the end, including when the run fails. Dive skips it when the run made no model calls.

<ResponseField name="usage.calls" type="integer">
  Model calls in the run.
</ResponseField>

<ResponseField name="usage.input_tokens" type="integer">
  Total uncached input tokens. `output_tokens`, `cache_creation_input_tokens` and `cache_read_input_tokens` sit alongside it.
</ResponseField>

<ResponseField name="usage.cost_usd" type="number">
  Total cost in USD. Present only when [`pricing`](/reference/configuration#param-pricing) covers a model the run used.
</ResponseField>

<ResponseField name="usage.by_step" type="object[]">
  The same totals per step, each with its `path`.
</ResponseField>

<ResponseField name="usage.by_model" type="object[]">
  The same totals per model, each with its `provider` and `model`.
</ResponseField>
